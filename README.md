# Prereborn Companion — official plugins

Signed plugin packages and catalog for Prereborn Companion.

Install through Companion → Plugins. Packages install disabled; installation never starts a worker.

Dota 2 0.1.0: Windows x64, IPC v1. Companion 0.5.91 supports disabled installation; manual External activation requires Companion 0.5.92 and verified backup/migration and process/audio/OBS fences. Native live smoke acceptance remains pending.

The catalog is published under `catalog-v1`; Dota under `dota2-v0.1.0`. Companion verifies signatures against its embedded official trust root. Private signing keys are never distributed.
